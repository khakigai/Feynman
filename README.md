# Feynman

경영학 · 제품 · 철학 · 삶 · 돈, 다섯 카테고리의 개념(약 200개)을 무작위로 뽑아,
AI 없이 리서치한 뒤 말로 설명하는 파인만식 학습 도구입니다.

- 리서치 10분 → 말하기 3분 (설정에서 변경)
- 셔플 덱: 한 바퀴를 다 돌기 전까지 같은 주제가 반복되지 않음 ('전체'는 모든 용어를 한 덱으로)
- 타이머가 도는 동안에는 새 주제 뽑기가 잠김
- 기록은 브라우저에 저장
- 단축키: Enter = 주제 뽑기, Space = 타이머 시작/정지

빌드 없는 정적 페이지(`index.html`) 하나로 되어 있어 GitHub Pages에서 바로 동작합니다.
단어 목록은 `index.html`의 `CATS` 배열에서 수정합니다.
